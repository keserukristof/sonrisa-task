# Screenshots

Visual evidence, named `<increment>-<what>-<viewport>.png`, for example `1-alert-form-mobile.png`.

- **Design review:** the approved artboards, saved by `/design` (next to their screen files in `docs/design/screens/`).
- **UX review:** what the `ux-reviewer` saw on each screen, at desktop and mobile width, referenced from its report in `docs/reviews/`.
- **Production:** the primary flow on the live site after each `/ship`.
- **Anything that went wrong** and was caught by looking: a screenshot of the problem, linked from the decision log.
